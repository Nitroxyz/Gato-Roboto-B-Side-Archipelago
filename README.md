# Gato Roboto B-Side
This mod has been created by an alternate devteam, with multiple speedrunners and returning people from the original randomizer.  
This mod integrates the Archipelago Randomizer with Gato Roboto. You can send and receive items and world progression in a multiworld containing multiple players.  
This randomizer shuffles the item upgrades, health upgrades, VHS items and each individual world event like the water levels. Additionally, you can add both the lore buttons and boss kills as additional locations.
With huge depth in the glitches and tech aspect of the game, you have multiple settings decicated just for balancing the randomizer to your skill level.  
The game also comes with some QoL features like unlockable warp points, a display for world progession and some crash fixes.
## Installation
1. Get the apworld in the [releases](https://github.com/Nitroxyz/Gato-Roboto-B-Side-Archipelago/releases) and install it in the apworld (double-click it if you have the Launcher installed)
2. Get your template via "Generate Template Option" or "Options Creator" button in the Archipelago Launcher
3. After installing the apworld, a Gato Roboto B-Side Client is available in the Archipelago Launcher (Relaunch the Launcher after installing)
4. Patch the game in the Client by running `/patch` (add directory path if you don't want to modify the default steam installation)
5. Connect to the Multiworld in the Client and open up the game 

Make sure to delete the current savefile before starting a new randomizer!  
If you are unsure about which locations are in logic or not, you can use the universal tracker with a built-in map!
# Current main features
## Unique Locations
- Item upgrades (Default)
- Health upgrades (Default)
- VHS palettes (Default)
- World progression (Default)
- Lore terminals (Optional)
- Boss kills (Optional)
## Difficulty Settings
- Gato Tech: A 3-stage difficulty setting, allowing for more unique and advanced tech on each tier
- Smallmech Glitch Toggle: Use the Smallmech to get around bosses and cat sections
- Watermech Glitch Toggle: Use the Watermech to get past water sections
## Game Settings
- Nexus Start: Start in the nexus instead of landing site, allowing for some rocket-less tech
- Early Goals: Adjust how many event items you need, allowing for quicker randomizers
- Local Rocket: Gives you a local rocket, preventing a long BK
- DeathLink: Deaths are shared across the MultiWorld
## QoL updates
- Pickup Notification: Added a custom notification when you pick up items which doesn't interrupt your gameplay
- Warp Overhaul: The warps have been fancied up to teleport your in style. Also prevents issues with warps breaking the logic
- Event Display: In the pause menu you can see how many event items you have and how many you need to open the incubator elevator
- Coordinate Locations: The location have been renamed to show coordinates to make it easier to find the item on the map
- Item name improvement: Progressive items don't have numbers anymore; VHS item names are shorter
- Old locations: The old location cutscene have returned, with slight adjustments. Item locations now show one random line from the game when you pick up an item ;)
- No vsync: Disabled vsync
- Run sync: If the game isn't synced, it will kick you out into the main menu
## Universal Tracker support
Thanks to the Poptracker Integration it will now show a full map of the game with each check with logic!  
Also includes yamlless support so you can generate the tracker without having to use a yaml and use weighted yamls.
## Other differences
- Seperated Heater Core items: LavaCooled is now seperated from FlowsCleared (Hotboys)
- New client icon: New client icon with a small chance for a shiny evil icon
- Rewritten guides: The setup guide and game guide has been rewritten
- Bugfixes: All Archipelago features have been restored in this APWorld
- Improved Logic: A signicantly more stable logic which has been tested by a group of experienced speedrunners and challenge players.
  - Better logic for Glitches
  - Smallmech in ventillation
  - Advanced tech to obtain certain items
  - Better fine-tuning for item qualities
  - No generation failiures
  - Improved world generation speeds
